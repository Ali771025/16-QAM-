# 16-QAM Mapping and Detection Exercises

Legacy MATLAB exercises for 16-QAM mapping and detection, with ASK/PSK/QAM comparisons over AWGN.

## Overview

One script compares ASK, PSK, and QAM over an AWGN channel. Another explicitly maps bit groups to 16-QAM constellation points and explores demodulation and detection.

## Requirements

MATLAB with legacy Communications Toolbox functions, including `randint` and `modem.*` APIs.

## Getting started

Clone this repository and open its directory:

```bash
git clone https://github.com/Ali771025/16-QAM-.git
cd 16-QAM-
```

Inspect the source and the compatibility notes below before setting up an execution environment.

## Compatibility and scope

These examples depend on old modem APIs and have not been migrated to current MATLAB functions. Review complex-number notation, constellation mapping, and bit-order conventions before relying on results.
